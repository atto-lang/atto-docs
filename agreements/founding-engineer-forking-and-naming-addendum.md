# AttoLang Founding Engineers Agreement — Forking and Naming Addendum

> **Status:** Proposed contractual addendum for legal review and execution. This is not a public software license. It is not binding on any Founding Engineer unless incorporated into, or separately executed alongside, the applicable Founding Engineers Agreement.

## 1. Purpose and scope

This addendum describes the limited rights granted to a person who has executed an AttoLang Founding Engineers Agreement (a **Founding Engineer**) to create an independent fork of the AttoLang project (the **Project**). It is intended to supplement, not replace, the intellectual-property, confidentiality, invention-assignment, and other obligations in that agreement.

For this addendum, **Project Owner** means the legal person or entity that owns or is authorized to license the relevant AttoLang source code and associated intellectual property, as identified in the applicable executed agreement.

## 2. Proprietary status; no public open-source license

AttoLang is currently **proprietary software** and has **not** been released under a public open-source license. Access to its code, membership in a development organization, or the ability to view or fork a repository does not, by itself, grant the public any right to use, redistribute, sublicense, or publish Project code.

All rights not expressly granted in a written agreement or an applicable license are reserved by the Project Owner.

## 3. Founding Engineers may fork

Subject to the Founding Engineers Agreement and this addendum, the Project Owner grants each Founding Engineer a non-exclusive, non-transferable right to make and maintain independent **private forks** of the Project's source code and to modify, build, test, and independently develop those forks.

This is an express contractual permission granted to eligible Founding Engineers, **not** an open-source license for the public. It does not transfer ownership of the original AttoLang code or other Project intellectual property.

Unless otherwise expressly authorized in writing by the Project Owner, this permission does **not** include a right to:
- publish or make the proprietary source code accessible to the public;
- distribute, sublicense, sell, or otherwise commercialize copies of proprietary Project code or derivative binaries;
- disclose confidential Project materials to third parties; or
- grant third parties rights to the proprietary code.

Any separate public-release, distribution, or commercial license should identify the permitted code, recipients, uses, and terms explicitly.

## 4. Independent naming and branding required

Any independent fork must adopt its **own distinct project name and branding**. A Founding Engineer must not name, market, publish, or present an independent fork using **“Atto”**, **“AttoLang”**, names containing **“Atto”**, or confusingly similar names.

Without the Project Owner's prior written permission, an independent fork must not use the Project's names, logos, visual identity, project domains, account identities, or other distinctive branding in:
- its product, language, compiler, runtime, repository, organization, package, or distribution name;
- its website, domain, marketing, documentation, or release materials; or
- statements implying the fork is an official AttoLang release, endorsed by AttoLang, or affiliated with the Project Owner.

This restriction concerns identifying a fork as a separate project; it does not prevent legally required attribution or accurate, non-promotional historical references where applicable law permits them, provided those references do not imply endorsement or affiliation.

## 5. Ownership, confidentiality, and third-party rights

The underlying AttoLang code and intellectual property remain subject to the Project Owner's existing rights. Ownership of a Founding Engineer's new contributions or independently created code is determined by the executed Founding Engineers Agreement and applicable law; this addendum does not override any agreed invention-assignment or work-product provisions.

Confidentiality duties remain in force. Third-party components remain subject to their own applicable licenses and restrictions. Permission to fork does not authorize the disclosure or use of third-party confidential materials.

## 6. Future licensing changes

If the Project Owner later releases specified AttoLang code under an open-source license, that released code may be used under the published license's terms. Such a release does not, by itself, license Project trademarks or change the independent-fork naming restrictions in this addendum to the extent enforceable under applicable law.

## 7. No voting or governance rights granted

The permission to fork in this addendum conveys **no corporate or Foundation equity**, shareholder or member voting rights, board or trustee seats, manager or officer appointment powers, veto rights, or governance authority. No ownership or governance powers are implied by Founding Engineer status alone.

Where a Founding Engineer separately signs the companion Founding Contributor Company Equity & Foundation Compensation Framework Agreement, the proposed **4% interest in AttoPL Co / Atto Co** is **non-voting** and governed by definitive Company equity documents. **Atto Foundation, if organized as a charitable 501(c)(3), does not issue private equity and has no 4% ownership award.** Any Foundation salary, service fee or IP royalty must arise from separately authorized and executed paid-work or genuine IP-license terms; founding status alone conveys **no ordinary Foundation voting rights, automatic salary, royalty, residuals or private distributions**.

## 8. Relationship to the main agreement

In the event of a conflict with the signed Founding Engineers Agreement, the parties should expressly identify in the executed documents which provision controls. This proposed addendum is not effective merely because it is stored in a repository.
